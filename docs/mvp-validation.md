# MVP検証記録

検証日：2026-11-16（日本時間）。対象：Issue #9の技術検証。実歌詞による有用性評価は未実施。

## 自作データでの検証

- 正解例：tests/test_evaluation.pyの自作30例。登録表現、文型、否定、行境界、タグ、具体的な情景、語の途中の非該当例を固定。
- 全テスト：171件成功。型チェック成功。自作例はルールどおりの一致を確認するものであり、芸術的な良し悪しや一般的なAI歌詞の精度を測るものではない。
- バックアップ：歌詞・改訂・タグ・辞書・除外・履歴・評価の往復一致、再起動後の読み取り、復元前の自動退避と退避ファイルからの再復元を検証。
- 破損／未対応版／不正な参照／歌詞ハッシュ不一致／履歴不一致を拒否し、現在のDBが保持されることを検証。退避ファイルを作成できない場合も現在のDBを保持。
- 画面テスト：バックアップ作成、復元プレビュー、確認前の復元無効、確認後の復元、評価の保存を確認。

## 性能計測

条件：evaluation.synthetic_lyricsが生成する自作20曲、各2,000文字。別の2,000文字を新規入力として比較。Streamlitの結果キャッシュは不使用。初回1回と、同一プロセスで辞書初期化後に3回測定。各回で比較対象／辞書の読込、比較、定型表現検出、結果統合、JSON化、SQLiteへの分析履歴保存を実行。DB準備・UI描画・ネットワーク時間は含まない。
